# Vitaly output form prototype

Interactive prototype of the PDF output form configurator (Figma: OpenLine-Vitaly, node 14002:280778).

- Left: form data sections. Each field can be shown or hidden; drag the dot handles to reorder fields and sections.
- Right: live PDF preview reflecting visibility and order. Hover a field to highlight it in the preview.

```
npm install
npm run dev   # http://localhost:5182
```

Live: https://tommyknocker81.github.io/vitaly-output-form-prototype/
